## Protest

DO NOT RESPECT PAYWALLS FOR BASIC TOURNAMENT MANAGEMENT.

Creating a tournament, managing players, recording results, generating rounds,
viewing standings, and finishing an event are basic functions—not premium
luxuries.

Building these basic features with AI or vibe coding and then demanding
unnecessary money from ordinary users is unacceptable.

CORE TOURNAMENT MANAGEMENT SHOULD REMAIN FREE.
